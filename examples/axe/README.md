# Wolf rune axe

This bundled example contains the input image, a rendered preview, and the
actual textured model produced by Sikander's Trellis 2.

![Input](source.png)
![Generated result](preview.png)

- [Download the generated GLB](game_ready.glb)
- Resolution: 1024; seed: 56; detailed mesh target: 300,000 triangles
- Texture resolution: 2048; low-poly target: 30,000 triangles
- Result: 28,384 triangles, embedded materials, watertight after merging UV seams for measurement
- Tested on an RTX 5070 Ti Laptop GPU with 12 GB VRAM and 32 GB RAM

The image comes from the [Comfy Org example asset collection](https://github.com/Comfy-Org/workflow_templates/blob/main/input/viking_wolf_rune_axe.png).
Its repository's MIT license is included in SOURCE-LICENSE.txt. The image is
an input example; no external workflow is required to run this app.
