A LITTLE DIRECTION

Meet your new creative space.

From a single image to a model you can make your own.

01 / INPUT

Give it a clear starting point.

Use one clearly visible object. Transparent PNGs work well. Click the axe example to try a prepared input.

02 / CREATE

Keep the first run simple.

Start at 1024 with 2K textures. TRELLIS.2 requires an NVIDIA GPU; CPU-only generation is not supported.

03 / EXPLORE

See every side.

Drag to orbit and scroll to zoom. Switch model versions below the viewer. Your library keeps previous creations within reach.

04 / EXPORT

Take it into your workflow.

Use textured.glb for detail or game_ready.glb for the smaller baked version. STL and final.glb contain untextured geometry.

A note on geometry

Each model version has its own topology check. Simplification can introduce openings, even when the detailed model is watertight. Check the selected version before printing. Imported-mesh repair removes original materials.
